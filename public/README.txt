COMO HOSPEDAR NO GITHUB PAGES:
------------------------------
1. Crie um novo repositório no seu GitHub (exemplo: "pranion-harmonizacao").
2. Faça o upload de todo o conteúdo desta pasta (com o index.html na raiz).
3. Vá em "Settings" > "Pages".
4. Em "Branch", selecione "main" (ou "master") e pasta "/ (root)".
5. Clique em "Save". Em poucos minutos, sua página estará no ar com HTTPS gratuito!

COMO HOSPEDAR NA VERCEL OU NETLIFY:
-----------------------------------
1. Acesse vercel.com ou netlify.com.
2. Conecte com o seu repositório do GitHub ou simplesmente arraste esta pasta para dentro do painel.
3. A publicação é instantânea!
